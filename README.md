# Waste Out of Wealth

## Project Title
**DIY Emergency Light Using Reused Materials**

## 1. Introduction
Waste Out of Wealth is a project that demonstrates how discarded or reusable materials can be converted into useful products. Our project focuses on creating a simple emergency light using basic electronic components and a reusable plastic box.

## 2. Problem Statement
During power cuts and unexpected situations, emergency lighting is essential. Instead of wasting available materials, we can reuse them to create a useful lighting solution.

## 3. Objective
- To create a simple emergency light.
- To encourage the reuse of materials.
- To reduce unnecessary waste.
- To promote creativity and sustainability.

## 4. Materials Required
1. Plastic box
2. Rechargeable battery
3. Connecting wires
4. Switch
5. LED

## 5. Working Principle
The rechargeable battery supplies electrical energy to the LED. The connecting wires provide the electrical connection between the components. The switch controls the ON and OFF operation of the LED. The plastic box holds and protects the components.

## 6. Advantages
- Reduces material waste.
- Encourages recycling and reuse.
- Useful during power cuts.
- Simple and cost-effective design.
- Promotes environmental awareness.

## 7. Applications
- Emergency lighting during power cuts.
- Temporary lighting in dark areas.
- Basic household emergency use.

## 8. Future Improvements
- Add automatic charging.
- Improve battery backup.
- Use a solar charging system.
- Improve the design and portability.

## 9. Conclusion
This project shows that reusable materials and simple electronic components can be transformed into a useful emergency light. It highlights the importance of creativity, recycling, and sustainable development.
